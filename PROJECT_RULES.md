# Правила разработки Windows-обоев

## Область изменений

Разрабатываются только живые обои Windows x64. Мобильная сцена, интерфейс, покупки, звук, офлайн-прогресс и экспорт удалены. Модель, геометрия, запасы, представление и сохранения служат Windows-обоям. При упрощении снимков сохраняй чтение ранее записанных сохранений обоев.

## Инварианты обоев

- Стройка автономна. Один носильщик с вместимостью 8. Экономика, покупки, игровой HUD и звук отсутствуют. После 900-й укладки результат показывается 5 секунд, затем начинается новый цикл.
- Модель работает вне сцены с шагом 0,1 с. Порядок исполнителей, фаз и назначения заданий детерминирован. Вид читает состояние и события. Координаты маршрутов задаёт модель, масштаб и смещения спрайтов задаёт представление.
- Ровно 900 ID и ровно один владелец на ID. Передача атомарна. Резервирует конкретный ID и место назначения; предел проверяется по физическому запасу и входным резервам.
- При смене ряда дождись активного подъёма на прежнюю площадку и возвращения строителя. Перестрой площадку с её запасами и проведи строителя на новый ряд.
- Сохраняется свой снимок обоев. При правке восстановления проверь очередность заданий, долю пройденного маршрута, остаток работы, резерв и черновые файлы записи. Небо продолжает следовать системному UTC, в том числе между циклами стройки.
- Меняя поведение, обнови [ГДД обоев](docs/GDD.md). В [журнале](PROGRESS.md) зафиксируй сделанное, проведённые проверки Windows и ближайший открытый шаг.
