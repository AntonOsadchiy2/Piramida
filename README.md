# Пирамида. Камень за камнем

Живые обои Windows x64. Стройка идёт за значками Explorer на основном мониторе. Движок Godot 4.7.2 stable, GDScript и рендерер Compatibility.

Репозиторий содержит только Windows-обои. Мобильная версия и архивные материалы доступны в истории Git до удаления Android-ветки.

## Живые обои Windows x64

Переносимый файл — [Piramida.exe](build/Piramida.exe). Требуются Windows 10 или 11 x64, Explorer и поддержка OpenGL 3.3. Стандартный чертёж содержит 900 блоков; в [локальной панели](tools/local-panel/README.md) можно задать свой. После последнего блока стройка показывает результат пять секунд и начинает новый цикл. При запуске незавершённая стройка возобновляется из своего сохранения. Небо следует часам ПК.

Значок в области уведомлений открывает правой кнопкой команды управления. Подменю «Скорость стройки» выбирает `×1`, `×4`, `×8`, `×16` или `×32`; выбор сохраняется между запусками и не ускоряет небо или погоду. Для остановки также можно завершить процесс `Piramida.exe` в диспетчере задач. Перед переносом или удалением отключите автозапуск, если включали его. Ранее созданный вручную ярлык в `shell:startup` удаляется отдельно.

## Разработка и сборка

В редакторе запускайте проект через F5 или сцену `scenes/wallpaper.tscn` через F6. Из корня проекта также можно выполнить `& $piramidaGodot --path . res://scenes/wallpaper.tscn`, указав в переменной полный путь к [консольному EXE Godot](docs/ACCEPTANCE.md#как-найти-godot). Этот запуск показывает сцену в окне. Встраивание за значки проверяется в собранном EXE.

Для сборки нужны консольный Godot 4.7.2 с шаблонами экспорта и инструменты Visual Studio C++ x64 с Windows SDK. Если запущен сам файл `build/Piramida.exe`, завершите его перед пересборкой.

```powershell
.\build-release.bat
```

Скрипт собирает EXE, проверяет, что файл создан, сохраняет прежний `build/Piramida.exe` как `build/Piramida-previous.exe` и удаляет более старые сборки. Если Godot лежит вне корня, передайте `-Godot <полный путь к консольному EXE>`. Сборка встраивает DLL и лицензии в EXE. При запуске они извлекаются в `%APPDATA%\Godot\app_userdata\Пирамида\desktop`. [Проверки обоев с изолированными данными](docs/ACCEPTANCE.md#автоматические-проверки)
