## Живые обои Windows x64

Переносимый файл — [Piramida.exe](build/Piramida.exe). Требуются Windows 10 или 11 x64, Explorer и поддержка OpenGL 3.3. После 900-го кирпича стройка показывает результат пять секунд и начинает новый цикл. При запуске незавершённая стройка возобновляется из своего сохранения. Небо следует часам ПК.

Значок в области уведомлений открывает правой кнопкой команды «Закрыть» и «Запускать при старте Windows». Для остановки также можно завершить процесс `Piramida.exe` в диспетчере задач. Перед переносом или удалением отключите автозапуск, если включали его. Ранее созданный вручную ярлык в `shell:startup` удаляется отдельно.

## Разработка и сборка

В редакторе откройте `scenes/wallpaper.tscn` и запустите именно эту сцену через F6. Из корня проекта также можно выполнить `& $piramidaGodot --path . res://scenes/wallpaper.tscn`, указав в переменной полный путь к [консольному EXE Godot](docs/ACCEPTANCE.md#как-найти-godot). Этот запуск показывает сцену в окне. Встраивание за значки проверяется в собранном EXE.

Для сборки нужны консольный Godot 4.7.2 с шаблонами экспорта и инструменты Visual Studio C++ x64 с Windows SDK. Если запущен сам файл `build/Piramida.exe`, завершите его перед пересборкой.

```powershell
pwsh -File tools/windows-wallpaper/build.ps1 -Godot $piramidaGodot
```

Сборка встраивает DLL и лицензии в EXE. При запуске они извлекаются в `%APPDATA%\Godot\app_userdata\Пирамида\desktop`. [Проверки обоев с изолированными данными](docs/ACCEPTANCE.md#автоматические-проверки)
