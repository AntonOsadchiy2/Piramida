# Работа с проектом «Пирамида»

**Единственная развиваемая версия — живые обои Windows x64.** Android-версия — замороженное legacy. Не дорабатывай, не исправляй, не собирай и не запускай её проверки. Не меняй её код, сцены, ассеты, конфигурацию экспорта и сохранения. Если задача для обоев затрагивает общий файл, помести изменение в ветку Windows-обоев или в отдельный модуль. Поведение мобильной ветки должно остаться прежним.

Начни с [README](README.md) и строки своей задачи в [карте архитектуры](docs/ARCHITECTURE.md). Правила обоев — в [ГДД](docs/GDD.md), проверки — в [приёмке](docs/ACCEPTANCE.md), порядок работ — в [плане оптимизации](docs/OPTIMIZATION.md). Соблюдай [инварианты](PROJECT_RULES.md). [Журнал](PROGRESS.md) используй для поиска конкретного решения.

Если команда `godot` не находится в PowerShell, проверь локальные пути из раздела [«Как найти Godot»](docs/ACCEPTANCE.md#как-найти-godot). На этом ПК консольный EXE есть вне `PATH`. Используй полный путь и выполни проверку Windows-сцены из приёмки, если она нужна для задачи. Если проверку выполнить не удалось, укажи проверенные пути или точную ошибку запуска.
