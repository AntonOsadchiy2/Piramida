# 14. HUD и покупки
Сделай верхнюю панель, четыре карточки ролей, найм, вместимость, индикаторы запасов и причины ожидания. Все цены и доступность приходят из модели; UI только отправляет команды. Диагностика учитывает соседние звенья, не объявляет носильщиков причиной по одному пустому складу. Обновляй интерфейс по изменениям, статистику с ограниченной частотой. Используй стандартные Control/Theme вместо отсутствующего арта, крупные зоны касания. Проверь покупки, пределы, нажатия и отсутствие конфликтов с камерой. Обнови PROGRESS.md.
